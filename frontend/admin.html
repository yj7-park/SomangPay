계좌이체 입금 확인 등록

통장에서 입금을 확인하면 여기에 입금자명(통장 표시 그대로)과 금액을 입력해 두세요. 회원이 제출한 충전 신청과 이름+금액이 일치하면 자동으로 충전됩니다. (실제 농협 계좌조회 API 연동 전까지의 임시 입력 방식)

입금 알림 자동감지 설정 (문자 + RCS/푸시 알림)

은행 입금 알림을 관리자 앱이 직접 인식해서 위 등록을 자동으로 처리합니다. 일반 SMS뿐 아니라 RCS(리치 문자)나 은행 앱 자체 푸시 알림처럼 SMS로 잡히지 않는 알림도 함께 감지합니다(아래 "알림 접근 권한" 필요). 문자를 보낸 발신번호/발신자와, 본문에서 입금자명·금액을 뽑아낼 정규식을 지정하세요 - 이 정규식은 문자/알림 두 경로 모두에 똑같이 적용됩니다. 이름은 (?<name>...), 금액은 (?<amount>...) 이름의 캡처 그룹으로 표시해야 합니다. 기본값은 NH농협 알림 문자(발신 1588-2100) 포맷 기준이며, 다른 은행이면 아래 값을 실제 형식에 맞게 바꾸세요. 같은 입금이 문자+알림 양쪽으로 동시에 들어와도 30초 이내 같은 입금자명·금액은 자동으로 중복 처리되지 않습니다.
